# Contributing

Thanks for your interest in HiMiao.

Good contributions include:

- Product data model improvements
- Multilingual content workflow improvements
- Admin review UX improvements
- FastAPI backend hardening
- Deployment documentation
- Demo data or seed workflow

Please avoid submitting:

- Real customer data
- Production databases
- Secrets, tokens, keys, private configs
- Copyrighted insurance materials without permission

## Pull Request Checklist

- Explain the user-facing change
- List touched frontend/backend modules
- Include verification steps
- Confirm no secrets or production data are included
